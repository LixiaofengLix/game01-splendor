交互规则

能点什么只看合法动作。筹码、卡、牌堆、贵族是否可点，全部由 Rules.get_legal_actions() 决定；界面不自己判断“看起来合法”。

拿宝石先选后确认。点不同色累积到 3 种；同色再点一次变成拿 2 枚（只有该色剩 ≥ 4 时才可能）；再点取消。可取颜色不足 3 种时，选 1–2 种也能确认。

买 / 预留走浮层。点卡出浮层，显示自动支付预览；设置里关掉“购买前确认”后，点可买的卡直接买。

弃宝石一次选够。界面收集 N 枚后，按顺序提交 N 个 discard 动作；中途收到 action_rejected 就重新打开弹窗。

非人类回合全锁。is_current_human() 为 false 时只能看、能开暂停菜单；电脑的弃宝石 / 选贵族不弹窗。

隐私。别人的盲抽牌一律画成牌背；电脑回合时 state_changed 带的是电脑自己的视图，它的盲抽牌也要画成牌背。同屏多个人类时换人先盖屏（09）。

反馈。每个事件对应一个动效：筹码飞到玩家面板、卡从场面滑走并补牌、贵族飞到得分区、到 15 分时分数跳动。电脑 / 远程玩家出手时，结果写进我的面板顶条 + 相关卡光晕 1.5 秒；市场上方永远不放浮层。持续状态（掉线、终局轮）用右栏提示卡或顶栏标签。

颜色永远配形状。任何表示宝石颜色的地方（筹码、折扣、花费、贵族要求、日志）都带专属形状；数量为 0 用空心描边。

缩放。按 1280×800 设计；Godot 用 canvas_items + expand。更宽的屏幕把多出来的宽度给右栏，更高的屏幕给市场卡牌放大；最小字号 12px（按 1280×800 计）。

座位号对用户从 1 开始（引擎里是 0 开始）；规则数值（15 分、10 枚、3 张）从 RulesConfig 读，不写死在界面里。

V4 本轮修改（像素风）：① 视觉整体换成像素风：深色木纹牌桌 + 羊皮纸面板，所有直角 / 缺角像素边框（9 宫格），按钮上亮下暗、悬停抬起、按下压扁，阴影一律是硬投影；② 字体换成像素字体，字号只用 12 / 24 / 48 三档（数字 8 / 16 / 32），保证整数倍清晰；③ 筹码改成 12×12 像素金币贴图，数量为 0 用空心金币；④ 宝石形状重画成点阵，并换成剪影差异更大的一组：白◇ 蓝● 绿▮（祖母绿切割）红♥ 黑■ 金★；⑤ 吉祥物改成 14×14 点阵；⑥ 选中卡上方有跳动的 ▼ 光标，刚被拿走的卡边框闪烁（按 steps 逐帧，不做平滑过渡）。
Godot 落地：边框用 StyleBoxTexture / NinePatchRect（本稿的 border-image 就是 9 宫格，切片 1 或 2 像素）；贴图导入时 Filter = Nearest；美术按 2px = 1 像素画，界面基准 1280×800、canvas_items 拉伸 + 整数倍缩放；字体打包 Fusion Pixel 12px 与 Press Start 2P（都是 OFL，可商用），关掉抗锯齿与 hinting。
V3：① 宝石颜色 + 专属形状双编码（色盲友好），宝石色加深；卡牌改为实色色带，黑白卡一眼可分；② 电脑出手结果写进我的面板顶条，掉线提示放右栏，市场上方不再有浮层；③ 拿宝石的确认 / 取消放到银行下方；④ 对手面板改为按颜色 6 列的网格，最小字号 12px，日志只露最近几条；⑤ 买不起的卡显示“差 N”并可悬停查看缺口，卡上标出哪些对手现在买得起；⑥ 去掉界面里的开发术语（座位类型 id、rules.json、schema、贵族 id）；⑦ 数量为 0 改为空心；⑧ 主题：衬线体用于标题 / 分数 / 罗马数字，贵族金边方牌，牌背斜纹，主菜单改成一组桌面静物；⑨ 去掉 Godot 难实现的虚线内圈和毛玻璃。
