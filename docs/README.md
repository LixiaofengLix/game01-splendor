# docs/

- `DEVELOPMENT_PLAN.md` — 开发计划（阶段划分与验收标准）。
- `PROGRESS.md` — 进度与偏差，跨会话交接的唯一依据。
- `tests/phase_N.md` — 每个阶段的测试用例（编号 / 前置条件 / 步骤 / 预期结果）。
- `CARD_LIST.md` — 由 `tests/data_report.tscn` 生成的卡表，供对照实体卡核对。
- `UI_INTEGRATION.md` — 正式 UI 的对接说明（阶段 3 起草，阶段 7 定稿）。
- `ui-preview.html` — 视觉风格参考样张。
- `ui-mockup-v4.html` — 正式 UI 的全部界面样张（V4 像素风，浏览器直接打开）：界面流程、各屏布局、交互规则与接口对照。
- `ui/` — 正式 UI 的开发文档（与逻辑阶段并行）：开发计划、视觉规范、各屏说明、交互规则、桥接层与接口需求；进度见 `ui/UI_PROGRESS.md`。
- `tests/ui_UN.md` — 正式 UI 各阶段的测试用例（编号 / 前置条件 / 步骤 / 预期结果）。
