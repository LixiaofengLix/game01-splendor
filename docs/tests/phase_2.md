## T2-01 规则自检：2000 局随机对局无违反

**前置条件**：无。

**步骤**

```bash
$GODOT --headless --path . tests/rules_selfcheck.tscn -- 2000; echo "退出码: $?"
```

**预期结果**：退出码 `0`，末尾为

```
随机对局：2000 局，共 284679 步，最长 273 步，平均 142.3 步
  预设局面：检查了 6 个 ✓

OK —— 共 523273 项检查全部通过，用时 133.2 秒。
```

（步数 / 用时每次略有差异，通过数应与上面同一个量级；失败时会打印
`✗ <人数> 人局 种子 <种子> 第 <步数> 步：<哪条不变量>` 并返回退出码 1。）

**覆盖的不变量**：宝石总数守恒、银行与玩家宝石不为负、回合末持币 ≤ 10、预留 ≤ 3、
每级卡牌守恒（牌堆 + 场面 + 预留 + 已购 = 40/30/20）、分数 = 卡牌分 + 贵族分、
`to_dict` → `from_dict` 往返一致、过滤视图不含隐藏信息、`duplicate_state` 副本独立、
同种子开局一致、重放一致、终局与胜者判定、非法动作被拒绝且状态不变、支付顺序。

## T2-03 用命令打完一整局（终局触发 → 本轮打完 → 结算）

**前置条件**：无（用预设局面 `endgame`：座位 0 已 14 分，场上有买得起的有分卡）。

**步骤**

```bash
cat > /tmp/t.txt <<'EOF'
load endgame
do 30
do 1
state
EOF
$CONSOLE -- --commands /tmp/t.txt
```

**预期结果**：`do 30` 是购买 `L2-K-02`（1 分）：

```
执行：购买 L2-K-02（2级 黑加成 1分 花费[白3 绿3 黑2]）
  · 座位 0 购买 L2-K-02（1 分，支付 白2 绿2 黑2）
  · 座位 0 达到 15 分，触发终局：本轮打完（所有人回合数相同）后结算
  · 座位 0 回合结束（已进行 1 个回合）
  · 轮到座位 1（第 1 回合）
```

此后座位 1 随便做一步（`do 1`），这一轮就打完（两人回合数都是 1），对局立即结束：

```
  · 对局结束（win_points）：座位 0 获胜；比分 座位 0 15 分，座位 1 0 分
★ 对局结束：座位 0 获胜
```

末局面的 `阶段 finished`，`结果` 行给出胜者。**注意**：触发终局的玩家不会再多打一回合，
所以 2 人局里"座位 0 触发 + 座位 1 走一步"就结束；4 人局要等到另外三家都走完。

## T2-04 拿三枚不同色；颜色不足 3 种时可以少拿

**前置条件**：无（用预设局面 `colors_short`：银行只剩白、蓝两色）。

**步骤**

```bash
cat > /tmp/t.txt <<'EOF'

EOF

```

**预期结果**：合法动作里没有"拿 3 枚不同色"，但有"拿 1 枚"和"拿 2 枚"：

```
   1) 拿 1 枚不同色：白
   2) 拿 1 枚不同色：蓝
   3) 拿 2 枚不同色：白 蓝
   4) 拿 2 枚同色：白
   5) 拿 2 枚同色：蓝
```

没有"拿 1 枚 / 拿 2 枚不同色"——这是规则开关 `allow_take_fewer_when_colors_short` 控制的行为。
