## T4-08 人机对战：2 人局（手工）

**前置条件**：无。

**步骤**

1. 启动主场景：

   ```bash
   $GODOT --path .
   ```

2. 设置界面保持默认（人数 2；座位 0 人类；座位 1 电脑（普通）），点「开始游戏」。
3. 正常玩到结束。重点观察：
   - 你的回合：动作按钮可用。
   - 你点完一步后：顶栏变成「轮到座位 1 · 电脑思考中…」，所有动作按钮立刻禁用。
   - 约 0.35 秒后电脑自动行动，事件日志出现它拿宝石 / 预留 / 购买 / 弃宝石的记录，然后回到你的回合。
   - 电脑买不起的卡「购买」按钮在它回合也是灰的（界面不能替它点）。
   - 对局到 15 分后弹出结算框，显示胜者和比分。

**预期结果**：不用操作座位 1，一局能正常打完；电脑回合没有可以点的动作按钮；
电脑的思考过程有可见的停顿（不是瞬间刷完），日志顺序正确。

## T4-10 三档难度体感（手工）

**前置条件**：无。

**步骤**

分别开三局 2 人局（座位 0 人类），座位 1 依次选「电脑（简单 / 普通 / 困难）」，
各走 15~30 步，观察电脑的行为：

1. 简单：偶尔拿一些奇怪的宝石组合、放弃明显能买的牌（约 10% 的随机失误）；
   对贵族 / 目标卡的规划较弱。
2. 普通：会围绕目标卡拿宝石、买折扣、抢贵族，偶尔预留你要的牌。
3. 困难：单步思考稍久（正常仍远低于 1 秒），更像在“算下一步”，阻挡 / 预留更积极。

**预期结果**：三档看起来有明确的强弱顺序；困难 AI 不会出现明显的非法操作或长时间卡住
（顶栏的「电脑思考中…」不应持续超过约 1 秒）。

> 机器模拟的胜率是：普通胜简单 63.5%，困难胜普通 60.5%，困难胜简单 67.0%（各 100 局）。
> 你只需要判断“手感上是否也符合这个顺序”，不需要复现具体胜率。
