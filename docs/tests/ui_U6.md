## U6-05 回放手感（需要你）

- 前置：无。
- 步骤：
  ```bash
  $GODOT --path . ui/app/app.tscn
  ```
  1. 主菜单 → 本地游戏，开一局 1 人类 + 电脑（或全人类），随便打 8–10 个回合。
  2. Esc → 暂停 →【保存】；回主菜单 →【读取存档】→ 选“快速存档”→【从头看回放】。
  3. 点【播放】，让回放走十几步，再点【暂停】；用【开头】【上一步】【下一步】【结尾】来回跳，
     点时间轴上的任意格子；切换 0.5x / 1x / 2x。
  4. 在“视角”里依次选 `全部公开` 和每个玩家名。
  5. 拖到中间某步，点【从这里接着玩】，确认后继续打两步。
  6. 回到主菜单 → 继续上一局（或读取存档）看这个新局能不能正常继续。
- 预期：
  - 打开回放没有明显卡顿（4 人长局也应该很快出画面）；时间轴颜色会在一两秒内从中间补齐，
    补齐过程中已播放的格子先是中性色，随后变成对应座位的颜色。
  - **时间轴的每一格 = 一步，颜色 = 这一步是谁行动的**；颜色和四个吉祥物一致
    （深棕 = 第 1 位，薄荷 = 第 2 位，紫 = 第 3 位，橙 = 第 4 位），时间轴上方有图例。
  - 点【下一步】/ 按 → / 自动播放时，会看到这一动的筹码飞行、卡牌滑走、补牌翻开、贵族来访，
    和正常对局一致；动效播完牌桌才变到下一步。时间轴点选和【上一步】是直接跳转，不播动效。
  - 播放 / 暂停跟手；← → 空格和按钮一致；到结尾会自动停；在结尾再点播放会从开头重播。
  - 2x 时步间隔只有 0.45 秒，如果上一步动效还没播完会先直接落到那一步再播下一步，
    看起来会有点快进，这是预期。
  - 当前步的格子加高并带橙框；右侧日志最新一条高亮，时间列是 `#步号`。
  - “全部公开”看不到任何人的盲抽正面；选某个玩家名时，只有轮到他行动的那些步能看到他自己的盲抽
    （这是 IR-03 之前的临时限制；其他步等同公开）。
  - 【从这里接着玩】的确认框写清楚会丢弃多少步；继续后的局面和回放当前步一致。
  - 每步说明读得懂（谁、做了什么），不出现卡牌 id。
- 需要你参与：回放节奏（0.9 秒 / 步是否合适）、跳转是否跟手、时间轴配色是否看得懂。
