## 人工重点（对照 `docs/ui-mockup-v4.html` 的 04 / 07 / 08）

1. **12px 像素字**：卡牌点数、花费、日志、标签清晰，不发糊；数字用 Press Start 2P。
2. **颜色 + 形状**：筹码是圆、折扣是方；白 / 金筹码用深灰形状，红绿色盲也能分。
3. **市场卡**：色带颜色 = 加成色；左上点数；右上彩色宝石形状；左下花费竖排；右下状态；卡右上头像不遮花费。
4. **我的面板**：左侧橙条、身份 / 资源 / 预留三列对齐；“宝石 N / 10”“预留 N / 3”数字来自视图与规则。
5. **对手面板**：6 列网格上下对齐；金币列折扣显示“—”；分数进度条在 12 分（胜利分 −3）后变橙；公开预留是彩色小块（数字 = 分数），盲抽是深色罗马数字块。
6. **日志**：最新一条暖色底；卡牌引用带浅色底和宝石形状；时间在右侧。
7. **牌桌几何**：顶部 44 顶栏；左栏 906 + 16 + 右栏 330；市场高 470、我的面板高 246；木纹底纹无接缝。
