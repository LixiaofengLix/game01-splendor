## U5-03 人机对局：动效是否看得清、会不会拖节奏（需要你）

- 前置：无。
- 步骤：
  ```bash
  $GODOT --path . ui/app/app.tscn
  ```
  1. 主菜单 → 本地游戏；用“单挑”或“标准 3 人”，把 1 个座位留成人类，其余选电脑（普通 / 困难均可）。
  2. 开局后拿一次 3 种颜色的宝石；等电脑出手；再试着买一张能买的卡、预留一张卡。
  3. 继续打到电脑触发购买 / 预留 / 弃宝石 / 贵族来访（贵族不一定每局都有，可用 U5-05 的预览看）。
- 预期：
  - 拿宝石：对应颜色的筹码从银行逐枚飞到自己面板，飞完银行和自己的数字才变。
  - 预留：卡从市场（盲抽时从牌堆）滑到预留区，若有金币会有一枚金币从银行飞过来；
    空出的卡位先盖一张牌背再翻开，牌背上只有等级和 ◆，**不写“盲抽”**。
  - 购买：卡滑向购买者面板，支付的筹码飞回银行；买到的卡有分 / 有折扣时，分数 / 折扣块跳两下。
  - 贵族：贵族牌从左侧贵族列飞到玩家面板，分数跳两下；选择贵族的弹窗在确认后立刻关闭，
    能看到飞行过程。
  - 弃宝石：弹窗确认后关闭，筹码从玩家面板飞回银行；日志里的连续弃宝石仍合并成一条。
  - 电脑回合动效不会挡住你的操作（界面锁定到落地为止）；落地后立刻恢复可点。
  - 节奏主观判断：标准速度下“看得清”，不出现等半天的感觉；4 人局连续电脑出手时不会越播越落后。
- 需要你参与：重点看节奏（太快看不清 / 太慢等得烦），以及弹窗关闭时机是否自然。

## U5-04 跳过与积压快进（需要你）

- 前置：进行中的对局，轮到电脑或正在播动效。
- 步骤：
  1. 电脑出手、动效正在飞时，点一下牌桌空白处。
  2. 再等下一次电脑出手，按一下 Esc（或 Enter）。
  3. 快速连续操作你的几个回合（例如拿宝石 → 下一轮马上再拿），观察是否卡死。
- 预期：
  - 第一下点击 / 按键直接跳到最新画面；这一下点击不会顺带选中卡或筹码（需要再点一次）。
  - 跳过不改变任何状态：银行、手牌、日志、分数和跳过前应有的结果一致。
  - 连续快速操作时积压不会无限增长（最多当前 + 排队 2 批），最终画面追上最新状态。
- 自动验证：`ui_smoke` 的 `_check_u5_fast_forward` / `_check_u5_skip_and_speed` 已覆盖队列与状态一致；
  手感需要你确认。
- 需要你参与：跳过是否跟手、第一下点击被“吃掉”是否能接受。

## U5-06 4 个电脑观战：不越播越落后（需要你，也可以只跑机器检查）

- 前置：无。
- 步骤：
  1. 正式入口 → 本地游戏 → “电脑对战”常用组合（4 个电脑，观战）。
  2. 连续看 1–2 分钟，期间注意日志和右栏分数是否持续更新、有没有卡住不动。
- 预期：
  - 电脑持续出手，画面 / 日志不会停住；积压时自动快进，不会越播越慢。
  - 牌桌没有卡死，暂停菜单 / 规则仍能打开。
- 自动验证：`ui_smoke` 的 `_check_u5_bot_spectator` 跑 4 个简单电脑 5 秒，检查积压 <= 2、
  画面落后不超过 3 个回合、全电脑观战没有可操作回合。
- 需要你参与：长时间观战是否顺畅；如果觉得快进太频繁或太慢，反馈节奏。
