# 视觉规范（V4 像素风）

> 数值来自 `docs/ui-mockup-v4.html` 最终生效的样式（V4 覆盖 V3 / V2 之后的结果）。
> 样张和本文不一致时以样张为准，并回来修正本文。所有尺寸按 1280×800 基准、逻辑像素计。

## 1. 像素原则

- 美术按 **2px = 1 个像素**画：12×12 的金币贴图显示成 24 / 36 / 48px（2× / 3× / 4×），不出现非整数倍。
- 贴图导入：Filter = Nearest、Mipmaps 关闭（`ui/app/app.tscn` 根节点设 `texture_filter = NEAREST`，子节点继承）。
- **没有圆角、没有模糊、没有平滑阴影**：阴影一律是向下偏移的硬投影；圆角用 9 宫格里的缺角 / 阶梯像素做。
- 动画按帧跳（相当于 CSS 的 `steps()`）：光标跳动、边框闪烁都是两帧交替，不做缓动。
  位移动画（筹码飞行）可以用 Tween，但位置要取整到 2px 网格。
- 不用着色器做毛玻璃。弹窗背后的遮罩是纯色半透明。

## 3. 字体

| 用途 | 字体 | 字号 |
|---|---|---|
| 所有文字 | Fusion Pixel 12px Proportional 简中（OFL） | **只用 12 / 24 / 48** |
| 数字（分数、点数、牌堆罗马数字、大号筹码数） | Press Start 2P（OFL） | **只用 8 / 16 / 32** |

- 字号映射：正文、标签、按钮、日志、说明一律 12；面板标题、弹窗标题、菜单按钮主文字 24（行高 1.4）；主菜单大标题 48（行高 1.3）。
- 数字：卡牌点数、对手分数、名次表分数、大号筹码数、大号折扣数、贵族大牌要求数 16；我的面板大分数 32。
  中号 / 小号筹码里的数字用像素字体 12。
- Godot 导入：Antialiasing = None、Hinting = None、Subpixel Positioning = Disabled、关闭 MSDF。
  字号写进 Theme 的 font_size 变体（`Small=12 / Title=24 / Hero=48`、`Num=16 / NumBig=32 / NumSmall=8`），零件里不散写字号。
- 字体文件和 `OFL.txt` 一起放进 `ui/theme/fonts/`。
- 最小字号 12px（按 1280×800 计）。

## 4. 像素贴图（`ui/tools/build_pixel_assets` 生成）

贴图全部由工具脚本用 `Image` API 画出、存成 PNG（`ui/assets/pixel/`），**不手画、不手改**。
点阵定义照搬样张页尾的 `<script>`（“V4 像素贴图”一段）：改样张就同步改工具，再重新生成。

### 4.1 9 宫格边框

| 名称 | 源尺寸 | 切片 | 显示边宽 | 形状 | 颜色变体 |
|---|---|---|---|---|---|
| 小框 `frame_s_*` | 3×3 | 1 | 2px | 四边 1px 描边、四角缺 1 个像素 | `ink #2a1c12`、`ok #2f9e5f`、`hot #e8582a`、`gold #8a6420`、`dark #120c08` |

- Godot：`StyleBoxTexture` 的边是按贴图原尺寸画的，不会放大，所以**直接生成 2× 的 PNG**
  （小框 6×6、`texture_margin_* = 2`；大框 10×10、`texture_margin_* = 4`），`expand_margin` 为 0，内容边距另设。
- 小框用在：按钮、tag、卡片、输入框、分段、下拉框、kbd、事件顶条、提示卡、toast、流程节点、返回按钮、发展卡、牌背。
- 大框用在：面板、弹窗、我的面板、对手面板、日志、银行、卡牌浮层、异常弹窗。
  大框面板另有：顶部 2px 内高光 `#fffaf0`、向下 4px 硬投影 `rgba(20,12,6,.45)`；重点面板（feature）顶部再加 4px `GOLD` 内条。

  - 身份：头像 50 + 名字（24 号）+ dark 标签“你 · 座位 N”；大分数（32）+“/ 15 分”；“已购卡 N 张 · 贵族 N 位”。
  - 资源：标签“宝石 N / 10”（超过上限时数字变 `DANGER`），6 枚 `md` 筹码；标签“折扣”，5 个 `md` 折扣块。
  - 预留：标签“预留 N / 3”，3 个迷你卡位（空位显示“空”）。
- 标签样式：12 号、`INK_3`，前面一个 7px 旋转 45° 的 `#c79a5b` 小方块。

### 6.8 对手面板 `UiOpponentPanel`

右栏，宽 330（减去内边距约 306），大框。

- 头部：头像 30 + 名字 + 类型标签（人类 / 电脑 · 困难 / 大模型〔purple〕/ 远程）+ 额外标签（思考中、离线、延迟）+ 右侧分数
  （Press Start 2P 16 +“/ 15”）。
- 分数进度条：高 6，按 分数 / 胜利分 填充；分数 ≥ 胜利分 − 3 时填充色变 `ORANGE`。
- 6 列网格（`CARD_SOFT` 底、2px `LINE` 框）：每列上面是折扣块（金币列显示“—”），下面是 `sm` 筹码，同一列 = 这个颜色的购买力。
  悬停一列显示“红：折扣 2 · 宝石 1”。
- 底行：“宝石 N / 10”（≥ 上限 − 1 时变 `DANGER`）· “贵族 N” · 右侧“预留”+ 迷你标记：
  公开预留画成 20×24 的彩色小块（本色底、数字是分数）；盲抽画成深色小块写罗马数字（Press Start 2P 8、`GOLD`）。
- 状态：当前行动 → 大框换 `hot` + 左侧 4px `ORANGE` 内条；离线 → 底色 `#eadcbc`、头像去色。
- 大模型思考中：面板底部多一个等待块（`CARD_SOFT` 底）：“DeepSeek · 第 1 次请求”、“12.4 / 30 秒” + 进度条。

### 6.9 日志 `UiLogPanel`

右栏剩余高度（最少 130），大框。标题行“对局日志” + 右侧“第 N 轮”计数。
每条：头像 16 + 文字（12 号，卡牌引用、宝石小图标内联）+ 右侧相对时间。最新一条用 `LOG_NEW` 底。
默认只露最近 7 条（3 个对手时 4 条，有掉线提示卡时 3 条），底部“全部记录 [L]”打开完整日志浮层（可滚动）。
大模型理由：在该条下面另起一行，左侧 3px `PURPLE` 竖线、`INK_2` 字。

卡牌引用 `UiCardRef`：`tint` 底的小块，“[形状] 二级红 · 1 分”。

### 6.10 顶栏 `UiHud`

高 44，`HUD` 底，文字全部 12 号。左：返回按钮（非牌桌屏）或加粗标题“璀璨宝石”、“3 人局 · 第 9 轮”标签、
可选的状态标签（终局轮、联网 · 主机）。正中：回合胶囊 `UiTurnPill`。右：“规则”“菜单 [Esc]”按钮，或回放 / 联网专用按钮。

### 6.11 卡牌浮层 `UiCardPopover`

宽 272，大框，出现在选中卡的右侧 14px、顶部对齐 −12px；超出牌桌右边界时翻到左侧。
内容从上到下：标题行（状态标签 + “二级 · 蓝 · 2 分”）→ 支付预览块（`CARD_SOFT` 底；三行“折扣 / 宝石 / 金币”，
每行列出用到的折扣块或逐枚 `sm` 筹码 + 右侧小结；买不起时改成“需要 / 已有”两行）→ 买后变化说明 →
按钮行（购买 accent + 预留 ghost）→ 快捷键提示。见 `INTERACTION.md` 第 3 节。

### 6.12 弹窗框 `UiModalFrame`、提示 `UiToast`、提示卡 `UiNoticeCard`

- 弹窗：大框 + 向下 6px 硬投影 `rgba(0,0,0,.5)`；内边距 22/24；标题 24 号，可以带 tag；底部按钮行右对齐。
  宽度：弃宝石 / 选贵族 560，结算 / 暂停 720，异常弹窗 420。
- toast：牌桌顶部居中（顶栏下 12px）；`EVENT_BG` + `hot` 小框；头像 + 一句话 + 说明；2.5s 后消失。
  **只用于“我刚做的事成功了”**（保存成功等），不用于别人出手、不用于持续状态，也不遮挡市场。
- 提示卡：右栏顶部，`EVENT_BG` + `hot` 小框，持续状态（掉线、代打）用，状态结束才移除。
