# 交互规则

> 对应样张“交互规则与接口对照”一节，加上落地时要定的细节。各屏的布局见 `SCREENS.md`。

## 1. 总原则

1. **视图是唯一真相**。每次 `view_updated` 都按新视图重画整桌；本地的选择状态（已选宝石、选中的卡）
   在重画后用新的合法动作重新校验，不合法就清掉。
2. **能点什么只看合法动作**（`TableSession.legal_actions()`）。筹码、卡、牌堆、预留卡、贵族能不能点，全部由它推出。
   界面拼出的动作提交前用 `Action.equals()` 在合法列表里找一遍，找到的那个对象才提交。
3. **非“我”的回合全锁**：`is_my_turn()` 为 false 时只能看、悬停、开暂停菜单、开完整日志。
4. **市场上方永远不放浮层**（卡牌浮层除外，它是我主动点出来的）。别人出手的结果写进我的面板顶条；
   持续状态（掉线、终局轮）用右栏提示卡或顶栏标签。
5. **颜色永远配形状**；数量为 0 用空心。
6. **对用户显示的座位号从 1 开始**（引擎里是 0 开始）；不显示卡牌 id、贵族 id、座位类型字符串、`rules.json` 之类的开发术语。

## 2. 拿宝石

本地状态 `selection: Dictionary[GemColor, int]`（每色 0 / 1 / 2）。点银行里某个颜色 `c`（金币和数量为 0 的不响应）：

| 当前 `selection[c]` | 结果 |
|---|---|
| 2 | 去掉 `c` |
| 1 | 如果只选了 `c` 一种，而且银行里 `c` ≥ `take_two_min_remaining`：变成 2；否则去掉 `c` |
| 0 | 如果已经有某色是 2：先清空。然后已选不到 3 种就加上 `c = 1`；已选 3 种就不响应 |

- **候选动作**：只有一种颜色而且是 2 枚 → `Action.take_two(c)`；否则 → `Action.take_three(已选颜色)`
  （颜色不足 3 种时规则允许少拿，这时 1–2 种的 `take_three` 会出现在合法列表里）。
- **确认按钮**：候选动作在合法列表里才启用（银行下方和顶条托盘的两个确认按钮同步）。
- **能点的颜色**：合法列表里至少有一个拿宝石动作包含这个颜色，才响应点击（悬停有反馈）；不能拿的颜色光标不变。
- **提示文案**（顶条左侧）：
  - 已选不到 3 种不同色：“再选 N 种不同颜色；同一颜色再点一次 = 拿 2 枚”；
  - 同色 2 枚：“同色 2 枚（蓝色银行剩 5 枚）”；
  - 三种：“三种不同颜色各 1 枚”；
  - 颜色不足 3 种、少拿也合法：“银行只剩 N 种颜色，可以少拿”；
  - 拿完会超上限（持有 + 本次 > `max_tokens`）时，上面几条都换成：“拿后 12 枚，确认后需要弃 2 枚”。
- 托盘：逐枚 `sm` 筹码 + “拿 白 蓝 黑 / 拿 2 枚蓝” + “拿后 N / 10” +【取消】【确认拿取】。
- 选宝石时点卡：清掉宝石选择，进入选卡。Esc / 取消 / 点空白处：清空。

## 3. 选卡与浮层

- 点场面卡、我的预留卡、牌堆：选中它（再点一次取消），右侧弹出浮层。同一时间只有一个选中项。
- 浮层按钮从合法动作推出：
  - 【购买】：`Action.purchase(card_id)` 在合法列表里才启用。
  - 【预留】：`Action.reserve_card(card_id)` / `Action.reserve_blind(level)` 在合法列表里才启用；
    禁用时写原因（预留已满 N 张）。是否附带金币：`reserve_takes_gold` 开关打开而且银行金币 > 0。
  - 我的预留卡只有【购买】；牌堆只有【盲抽预留】。
- **支付预览**：`ViewMath.payment_preview(view, seat, card_id)`：每色先用折扣抵、再用同色宝石、差额用金币补
  （和 `Rules` 一致，见 IR-02）。显示三行：折扣（用到的折扣块）、宝石（逐枚筹码）、金币（逐枚）；
  再写“买后：宝石 a → b，X 色折扣 c → c+1，分数 s → s+p”。买不起时显示“需要 / 已有”和“还差 N”。
- **“差 N”**：N = 用完折扣、同色宝石、金币之后还缺的枚数。悬停的缺口条逐色列出缺多少，再写“金币可抵 K”。
- **对手买得起**：对每个对手（“我”以外的座位）用他的公开宝石 + 折扣算一遍，缺口为 0 就在卡右上放他的 16px 头像。
  电脑回合、回放时照样显示（回放里对所有玩家算）。
- 快捷键：Enter = 购买（不可买时无效），R = 预留，Esc = 取消选中。
- 设置“购买前确认”关掉时：点一张“可买”的卡直接提交购买，不弹浮层；点买不起的卡仍然弹浮层（用于预留）。
- 提交后清空选中。

## 4. 回合内弹窗的提交

视图的 `phase` 决定弹哪个窗，**不靠事件**（事件可能被动效队列延后，视图不会）：

| `phase` | 当前座位是“我” | 不是“我” |
|---|---|---|
| `discard` | 打开弃宝石弹窗 | 不弹窗；顶条写“X 正在弃宝石” |
| `choose_noble` | 打开选贵族弹窗 | 不弹窗 |
| `finished` | 动效播完后打开结算 | 同左 |

- **弃宝石**：需要弃的枚数 = 持有总数 − `max_tokens`。界面一次选够再确认，然后**按选择顺序逐个提交** N 个 `Action.discard(color)`。
  引擎每弃 1 枚就发一次 `view_updated`（阶段仍是 `discard`），界面在提交过程中不重开弹窗；
  全部提交完、阶段离开 `discard` 才关。中途某个被拒（`action_failed`）：用最新视图重新打开弹窗，已经弃掉的不再算。
- **选贵族**：候选 = 视图 `pending_nobles`；选一位 → `Action.choose_noble(id)`。
- 两个弹窗都不能取消，Esc 不关它们（但可以叠开暂停菜单）。

## 5. “我”、锁定、隐私、换人遮挡

- **本机座位**：类型为人类的座位（联网时只有自己的座位）。
- **“我”**：
  - 当前座位是本机座位 → “我” = 当前座位；
  - 否则 → “我” = 最近一个行动过的本机座位（开局时是座位号最小的本机座位）；
  - 没有本机座位 → 观战，没有“我”。
- **锁定**：`is_my_turn()` = 当前座位是本机座位，而且对局在进行中（对应 `GameController.is_current_human()`）。
- **盲抽隐私**：
  - 别人的盲抽预留一律画牌背（视图里 id 为 `null`）。
  - 轮到电脑时，`state_changed` 给的是**电脑自己的视图**，里面有电脑的盲抽牌 id——**界面也要画成牌背**
    （桥接层统一处理：只有 viewer 是“我”的时候，才显示 viewer 自己的盲抽正面）。
  - 反过来，电脑视图里“我”的盲抽是 `null`。我的面板要显示我自己的盲抽，靠 IR-01（按座位取视图）；
    IR-01 前桥接层缓存：每次 viewer 是本机座位时，记下该座位预留卡的 id，在别人回合用缓存补上。
    （预留卡只会在自己的回合变化，所以缓存是准的。）
- **换人遮挡（09）**：开关打开、本机座位 ≥ 2 时，满足下面条件就先盖屏，点按钮后才渲染牌桌：
  新视图的当前座位是本机座位，而且和上一次遮挡放行的座位不同。
  盖屏期间牌桌不渲染这个人的私密信息（盖屏是实色，下面的牌桌可以先画好，但盲抽正面等放行后再填）。
  总结卡写上一位本机座位行动之后、别人做的最后一件事（多件时写“等 3 个动作”）。

## 6. 我的面板顶条

| 场景 | 顶条内容 |
|---|---|
| 轮到我，什么都没选 | “● 轮到你：点银行拿宝石，或点一张卡购买 / 预留” + 托盘（还没选宝石，确认禁用） |
| 选宝石中 | 第 2 节的提示 + 托盘 |
| 选中卡 | “● 已选中 二级蓝卡 —— 在浮层里购买或预留，点空白处取消” + 托盘（没有选宝石） |
| 弃宝石 / 选贵族 | “● 持币超过上限，先弃回银行” / “● 回合末：贵族来访” |
| 别人刚出手（事件态） | “[头像] **薄荷** 预留了 [二级红 · 1 分]　拿到 1 枚金币 · 现在轮到紫晶” + 右侧“刚刚” |
| 别人思考中、还没新事件 | “● 等 紫晶 出手…你可以先看看场面” |
| 终局轮 | “[头像] **小明 到 15 分了！**　终局轮：薄荷、紫晶、橘子各还有一回合，之后结算” + 右侧“终局轮” |
| 大模型兜底 | “[头像] **紫晶** 的大模型回复两次都解析失败　这一步已由困难电脑代打” |

事件态在下一次轮到我时换回操作提示。

## 7. 事件 → 动效 / 日志 / 顶条

事件来自 `events_arrived`（每个元素是 `GameEvent.to_dict()`）。它和 `view_updated` 的顺序是：**先事件、后视图**；
电脑弃宝石 / 选贵族不等待，所以一帧里可能连续来好几批。处理方式：

- 收到视图：立刻更新“目标视图”，但牌桌先保持在动效起点，动效队列播完（或被跳过）后再落到目标视图。
- 动效队列按事件顺序播放；积压超过 2 批时快进（直接落到最新视图，只保留最后一批的光晕）。
- 动画速度：慢 ×1.5 / 标准 ×1 / 快 ×0.5；回放和观战另有自己的速度。
- 动效永远不改状态，跳过它不影响任何东西。

| 事件 | 动效（标准速度） | 日志 / 顶条 |
|---|---|---|
| `gems_taken` | 每枚筹码从银行飞到玩家面板（间隔 60ms，单枚 300ms），银行数字逐个跳 | “紫晶 拿了 [白][绿][黑] 各 1 枚” / “拿了 2 枚 [蓝]” |
| `card_reserved` | 卡从场面（或盲抽时牌背从牌堆）滑到玩家预留区；有金币时一枚金币从银行飞过去；补牌翻开 | “薄荷 预留 [二级红 · 1 分]，拿到 1 枚 [金]” / “盲抽预留了三级牌堆顶（没有金币了）”；相关卡位光晕 1.5s |
| `card_purchased` | 支付的筹码从玩家飞回银行，卡滑到玩家面板，折扣块 +1 跳一下，分数跳动；补牌翻开 | “小明 购买 [一级白]，付 [红]×1”；光晕 |
| `gems_discarded` | 一枚筹码从玩家飞回银行 | 连续的弃宝石合并成一条：“紫晶 弃回 [绿][红]” |
| `noble_visited` | 贵族从贵族列飞到玩家面板，分数 +3 弹出 | “贵族（白 4 蓝 4）来拜访小明（+3 分）” |
| `endgame_triggered` | 触发者分数放大跳动两下 | 顶栏加“终局轮 · 还剩 N 人”；顶条终局轮文案 |
| `player_skipped` | 无 | “X 没有可以做的动作，跳过这一回合” |
| `turn_started` | 胶囊切换；对手面板 `hot` 框移动 | 无 |
| `game_finished` | 等队列播完，弹结算 | “对局结束” |
| `discard_required` / `noble_choice_required` / `turn_ended` | 无（弹窗由 `phase` 决定） | 无 |

- 日志里的时间写相对时间（刚刚 / 20 秒 / 1 分钟），回放里写步号（#37）。
- 卡牌引用 = “[形状] 二级红 · 1 分”；0 分不写分数。
- 贵族引用 = 按要求描述（“白 4 蓝 4 的贵族”），不写 id。
- 音效钩子：`gems_taken`、`card_purchased`、`card_reserved`、`noble_visited`、`endgame_triggered`、`game_finished`、按钮点击；
  U5 只留调用点和开关，素材以后再放。

## 8. 快捷键

| 键 | 作用 |
|---|---|
| 1–5 | 按 白 蓝 绿 红 黑 的顺序点银行筹码（同第 2 节规则） |
| Enter | 确认拿取 / 浮层里购买 / 弹窗主按钮 / 换人遮挡的开始按钮 |
| R | 浮层里预留 |
| Esc | 取消当前选择；什么都没选时打开 / 关闭暂停菜单 |
| L | 打开 / 关闭完整日志 |
| 回放里：← / → / 空格 | 上一步 / 下一步 / 播放暂停 |

键盘焦点可见：3px `ORANGE` 外框。所有按钮都能用 Tab 走到。

## 9. 文案规则

- 规则数值一律从 `RulesConfig` 拼：胜利分、持币上限、预留上限、拿 2 枚的阈值、每色宝石数、金币数、贵族数。
- 玩家类型显示名：人类 / 电脑 · 简单 / 电脑 · 普通 / 电脑 · 困难 / 大模型 / 远程。
- 颜色名：白 / 蓝 / 绿 / 红 / 黑 / 金（`Enums.color_to_zh()`）。
- “轮”：显示 `turn_counts[current_seat] + 1`（当前玩家的第几回合；同一轮里大家相同或差 1）。
- 时间：保存时间显示“10 分钟前 / 昨天 / 10-14”。

## 10. 动作被拒

`action_failed(message)` 时：清掉本地选择，在顶条写一行“这一步没成功：<message>，请重新选择”（3 秒后恢复），
日志不写。按理只会在点击过期时出现（例如双击）。
