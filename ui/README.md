# ui/

正式 UI（UI 线）。入口是 `app/app.tscn`；开发计划、视觉规范与桥接约定见 `docs/ui/`。

- `app/` — 入口场景：屏幕路由、弹窗层、toast 层、全局快捷键。
- `theme/` — 调色板、Theme 资源、字体与许可证。
- `assets/` — 工具生成的像素贴图与预留音效。
- `tools/` — 资源生成工具（贴图）。
- `bridge/` — 唯一调用逻辑层的地方。
- `common/` — 从视图计算显示数据的纯函数与文案。
- `components/` — 可复用零件。
- `screens/` — 各屏幕。
- `dev/` — 零件陈列、截图与测试夹具。
