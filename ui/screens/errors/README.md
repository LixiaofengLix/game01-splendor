# ui/screens/errors/

启动与读档的异常提示（`error_modal.gd` / `UiErrorModal`）。由应用入口加到 `ModalLayer`。

- 21 数据加载失败：眯眼吉祥物、标题、逐条错误（文件名 + 原因）、说明、【复制错误】【退出】。
  启动时 `DataRegistry.is_valid()` 为 false 就显示，不进主菜单。
- 22 存档无法读取：原因标签（版本太新 / 文件损坏 / 不认识的类型 / 重放校验失败）+ 一句人话说明；
  原始错误放在可展开的“详细信息”里；【返回列表】关闭弹窗。
  “读到第 N 步为止”要等 IR-03，U4 不显示。
