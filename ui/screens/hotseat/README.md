# ui/screens/hotseat/

09 同屏换人遮挡（`hotseat_cover.gd` / `UiHotseatCover`）。

- 整屏实色（羊皮纸平铺）盖住，防止下一位玩家看到上一位的宝石和盲抽牌。
- 内容：上一位的半透明头像 + 下一位的大头像、dark 标签“同屏 · 换人”、“轮到 某某”、
  一张总结上一位之后动作的小卡、“我是某某，开始我的回合”按钮。
- 出现条件由 `UiTableFlow` 判断：开关打开、本机座位 ≥ 2、新视图的当前座位是本机座位、
  而且和上一次放行的座位不同；对局结束时不再遮挡。
- 遮挡期间牌桌不渲染（`UiTableFlow._render()` 直接返回），收起后才把待显示的视图落到牌桌上。
