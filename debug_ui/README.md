# debug_ui/

最小可验证界面，全部用 Control + Button + Label，不做美术。将来被正式 UI 整体替换。

- `main/` — 调试入口：在设置界面与棋盘之间切换（`run/main_scene`）。
- `setup/` — 开局设置：人数、种子、座位类型（阶段 5 起可选人类 / 三档电脑 / 大模型；
  大模型座位选择配置档；默认座位 0 人类、其余普通电脑）。
- `board/` — 最小可视化桌面：银行、卡牌、贵族、玩家面板、弃宝石 / 选贵族弹窗、事件日志、
  存档 / 读档 / 重放、预设局面。电脑 / 大模型回合会禁用动作按钮并显示思考状态
  （大模型显示已等待秒数），同时遮蔽它们自己盲抽预留的牌；大模型的理由和兜底会写进日志。
- `llm_settings/` — 大模型配置面板：配置档增删改、连接参数、测试连接；写入 `user://config.json`。
- `console/` — 文本调试台（阶段 2）：显式用 `godot --path . debug_ui/console/console.tscn` 打开。
