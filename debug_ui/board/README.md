# debug_ui/board/

最小可视化桌面（阶段 3）。只读 GameController 发来的过滤视图，不访问 GameState。

- 拿宝石：底部“拿宝石”按钮（拿三枚 / 拿两枚 / 颜色不足时的少拿）。
- 卡牌：每张牌上的“购买”“预留”；牌堆的“盲抽预留”。
- 弃宝石、选贵族：进入对应阶段时弹出选择框，其他操作不可点。
- 顶部：存档 / 读档 / 重放（固定文件 `user://saves/board_quick.json`）、预设局面、返回设置。
- 右下：事件日志。玩家面板可滚动（4 人局时）。
- 阶段 4：轮到电脑时动作按钮全部禁用、顶栏显示“电脑思考中…”，弃宝石 / 选贵族弹窗不显示
  （AI 自己处理）；当前电脑的盲抽预留牌对同屏人类保持隐藏。

界面冒烟测试：`godot --headless --path . tests/board_smoke.tscn`。
